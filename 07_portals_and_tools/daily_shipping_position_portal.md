# Daily Shipping Position Live System

- **Official URL:** [https://shippos.nigerianports.gov.ng/](https://shippos.nigerianports.gov.ng/)
- **Classification:** External Digital Portal / E-Services System

## Overview
Real-time vessel movements, expected vessels, berthing schedules, and vessels at berth across all Nigerian port complexes (Lagos Port Complex Apapa, Tin Can Island, Rivers Port Harcourt, Onne, Delta/Warri, Calabar, and Lekki).

## Core Capabilities & Features
- Expected vessels schedule with ETA, vessel name, agent, and cargo specifications
- Vessels currently alongside berths across all ports
- Vessels waiting at anchorage / fairway buoys
- Historical shipping position archives

## Technical Details
- **Hosting / Subdomain:** `https://shippos.nigerianports.gov.ng/`
- **Security:** HTTPS secured with authenticated access controls.
- **Support & Inquiries:** Contact NPA Headquarters / Port Operation centers for portal authorization.
